# Backlog Agent

このエージェントは、Backlog APIを使用してユーザー情報を取得するためのツールです。

## 機能

- Backlog OAuth2認証
- ユーザー情報の取得と表示
- ウェブUIによる簡単な操作

## 設定方法

1. `.env`ファイルを作成し、以下の環境変数を設定します：
   ```
   GOOGLE_API_KEY=あなたのGemini APIキー
   ```

2. 必要なパッケージをインストールします：
   ```
   pip install -r requirements.txt
   ```

## 使用方法

1. エージェントを起動します：
   ```
   python3 take_issue_agent/main.py
   ```

2. ウェブブラウザが開き、エージェントとのインタラクションが始まります。

3. エージェントの指示に従い、Backlogの認証を完了させます：
   - 表示されるURLをコピーして新しいタブで開きます
   - Backlogで認証を行います
   - リダイレクト後のURLから認証コードを抽出します
   - エージェントに認証コードを提供します

4. 認証が成功すると、あなたのBacklogユーザー情報が表示されます。

## アーキテクチャ

エージェントは以下のコンポーネントで構成されています：

- `agent.py`: メインエージェントの定義
- `main.py`: エージェントの起動と実行
- `tools/backlog_auth_tool.py`: Backlog認証とAPI通信ツール

## トラブルシューティング

- **認証エラー**: 認証コードは一度しか使用できません。エラーが発生した場合は、認証プロセスを最初からやり直してください。
- **API接続エラー**: インターネット接続やBacklog APIの状態を確認してください。

# Hackathon Agents

このリポジトリには、さまざまなAIエージェントが含まれています。

## エージェント一覧

### 1. Backlog Agent
Backlog APIを使用してユーザー情報を取得するエージェントです。
詳細は[こちら](take_issue_agent/README.md)を参照してください。

### 2. ランチ推薦エージェント
位置情報と休憩予測を使用して適切なランチスポットを推薦するエージェントです。

### 3. カレンダーエージェント
Googleカレンダーから予定を取得するエージェントです。

## 使用方法

各エージェントディレクトリ内のREADMEを参照してください。
